# Documentos de domínio

Este repositório usa contexto único.

Antes de explorar ou alterar código, ler `CONTEXT.md`, as seções relevantes de `docs/SPEC.md`, `docs/decisions.md` e os ADRs da área em `docs/adr/`. Não interpretar o template de ADR como decisão aprovada.

Usar os termos do glossário em issues, testes e interface. Se houver ambiguidade, registrar a lacuna em vez de inventar significado. Quando uma mudança contrariar uma decisão aceita, explicitar o conflito e atualizar a decisão com justificativa.

`docs/SPEC.md` preserva o anexo original. Alterações posteriores acordadas são registradas em decisões/ADRs e nas issues; manter rastreável qual decisão altera qual requisito.
