# Sonda · Market Analyst

Ferramenta privada de análise de mercado guiada para hackathons (Sprint) e projetos para vender (Venture). Interface e documentação em PT-BR.

**Estado:** planejamento aprovado, com quatro milestones e 29 issues publicados. Aplicação, banco e deploy ainda não implementados.

Primeira entrega: [#1 — Layout Ascensão e checks automatizados](https://github.com/Cerne17/market-analyst/issues/1).

Segredos e chaves devem ficar fora do Git. O template de ambiente e as instruções de execução serão adicionados com a aplicação.
